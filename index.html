How a file gets made

  1. You send the files and the count. I answer the same day with a fixed price and a delivery date — no hourly billing, no surprises at the end.
  2. The first batch comes early. Often a few records, so you approve the format before I run the rest of the set.
  3. Two passes over every page. Then a check sheet: column totals recomputed, row counts matched, dates and amounts stored as numbers rather than text.
  4. The deliverable. The file, a short report of anything unclear, and no open questions left for you to sort out.
